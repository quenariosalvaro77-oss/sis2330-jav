# Semana 02 - Fundamentos de Java

## Qué se hizo
Se practicaron los conceptos básicos de Java: tipos primitivos, operadores, estructuras de control, arrays y métodos. Todo el código está en la carpeta `src/`.

## Archivos
* `src/Ejemplos.java`: Pruebas de variables, operadores lógicos y cortocircuito.
* `src/Calculadora.java`: Implementación de un método para calcular el promedio de un array, demostrando el uso de cast `(double)`.

## Qué se aprendió
* Diferencia entre `7 / 2` (división entera) y `(double) 7 / 2`.
* Uso del operador `%` para obtener el resto.
* Recorrido de arrays con `for` clásico y `for-each`.
